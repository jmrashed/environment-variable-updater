# Security Policy

## Supported Versions

We take security seriously. The following versions of the Environment Variable Updater are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly. We appreciate your help in keeping our users safe.

### How to Report

Please report security vulnerabilities by emailing the maintainers at [jmrashed@gmail.com](mailto:jmrashed@gmail.com). Include the following information:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact and severity
- Any suggested fixes or mitigations

### What to Expect

- **Acknowledgment**: We will acknowledge receipt of your report within 48 hours.
- **Investigation**: We will investigate the issue and provide regular updates on our progress.
- **Resolution**: Once the issue is resolved, we will notify you and publicly disclose the vulnerability after a reasonable period for users to update.
- **Credit**: We will credit you (if desired) in our security advisory.

### Responsible Disclosure

Please allow us time to investigate and fix the issue before publicly disclosing it. We ask that you give us at least 90 days to resolve the issue.

## Security Best Practices

When using this tool, please follow these security best practices:

- Never commit sensitive environment variables (passwords, API keys) to version control
- Use the provided backup functionality to avoid data loss
- Regularly review and update your environment configurations
- Limit access to environment files to authorized personnel only

## Contact

For security-related questions or concerns, contact the maintainers at [jmrashed@gmail.com](mailto:jmrashed@gmail.com).
